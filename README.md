# rar2hashcat

rar2hashcat processes input RAR files into a format suitable for use with hashcat.

rar2hashcat is based on rar2john.

## Usage

1. Run `rar2hashcat [rar files]`. Output goes to stdout.
2. Run hashcat on the output generated by rar2hashcat.

## Building

### Linux / Windows (cross-compiled, GNU Make)

    make

Builds the Linux binary (`rar2hashcat`, via `gcc`) and the Windows
cross-compiled binary (`rar2hashcat.exe`, via `x86_64-w64-mingw32-gcc`).
`make clean` removes both.

### Windows (MSVC, native, nmake)

You need `MSVC` installed and a shell with the `MSVC` paths set (e.g. run `vcvarsall.bat x64` in a `cmd` shell, or launch the `Developer PowerShell for VS` link from the start menu for `PowerShell`).

Under `cmd` run:
```
build_msvc.bat
```

to compile and link, or

```
build_msvc.bat clean
```

to clean.

The same from `PowerShell`, but the script is named `build_msvc.ps1`

Or, skipping the wrapper, call `nmake` directly:
```
nmake /f Makefile.msc
```

This builds the native Windows binary (`rar2hashcat.exe`) using the `MSVC`
`cl` compiler.

```
nmake /f Makefile.msc clean
```

removes the build artifacts.

Both the mingw-cross and MSVC-native builds emit `rar2hashcat.exe` in this
directory; since only one toolchain is normally installed at a time, there is
no real conflict.
