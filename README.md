# rar2hashcat

rar2hashcat processes input RAR files into a format suitable for use with hashcat.

rar2hashcat is based on rar2john.

## Building

Linux and Windows (mingw-w64 cross-compile):

```
make
```

Windows with the native MSVC toolchain, from a Developer Command Prompt:

```
nmake /f Makefile.msvc
```
